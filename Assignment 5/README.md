# C# Assignment 5

This project contains a complete, runnable C# console application for Assignment 5.

## Included Programs

1. Student Details
2. Arithmetic Operations
3. Number Check
4. Calculator
5. Array Operations
6. Employee Class
7. Inheritance Demo
8. Method Overloading
9. Exception Handling
10. OOP / Polymorphism Demo

## Run the project

From the project folder:

```bash
dotnet build

dotnet run
```

or from the workspace root:

```bash
dotnet run --project "assigment 5/Assignment5.csproj"
```

## Notes

This assignment is designed to practice:
- C# syntax and console input/output
- control structures
- arrays and loops
- classes and objects
- inheritance and polymorphism
- method overloading
- exception handling
