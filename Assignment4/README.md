# Assignment 4

This is a random C# assignment project created as a console application.

## Included tasks

- Student Registration
- Simple Calculator
- Array Analysis
- Employee Details
- Number Guessing Game
- Shape Demo

## Run in Visual Studio

1. Open `Assignment4.sln` in Visual Studio.
2. Press `F5` to run the project.

## Run from terminal

```bash
dotnet build

dotnet run
```
