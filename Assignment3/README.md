# Assignment 3

This is a C# console application for basic programming exercises.

## Included Programs

- Student Details
- Sum of Numbers
- Even or Odd
- Largest of Three Numbers
- Factorial

## Run in Visual Studio

1. Open the project folder in Visual Studio.
2. Open `Assignment3.csproj`.
3. Press F5 to run the project.

## Run from terminal

```bash
dotnet build

dotnet run
```
