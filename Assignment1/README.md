# .NET Framework Lab Assignment 1

This repository contains the solutions to the .NET Framework Lab Assignment 1. All programs are written in C# and designed as Console Applications targeting the .NET Framework.

## Project Structure

Each question is solved in a separate C# file following a consistent template and utilizing simple, beginner-level programming constructs.

- Q1.cs: Input student details (Name, Roll Number, Marks) and display them in a formatted manner.
- Q2.cs: Input two numbers and calculate their Sum, Difference, Product, Quotient, and Remainder.
- Q3.cs: Determine if a number is Positive, Negative, or Zero using if-else.
- Q4.cs: Grade student marks based on a specific scoring range (O, A+, A, B+, B, Fail).
- Q5.cs: Simple calculator demonstrating addition, subtraction, multiplication, and division using a switch statement.
- Q6.cs: Print all Even and Odd numbers between 1 and N.
- Q7.cs: Calculate the Factorial of a positive integer using a for loop.
- Q8.cs: Check whether a number is Prime or Not Prime.
- Q9.cs: Check whether a number is a Palindrome Number.
- Q10.cs: Menu-driven program (Check Even/Odd, Find Largest of Three, Calculate Factorial, Exit).

## How to Run

1. Open Visual Studio 2022.
2. Create a new project using the "Console App (.NET Framework)" template.
3. Replace the auto-generated Program.cs file content with the code from any of the question files (Q1.cs through Q10.cs).
4. Build and run the project by pressing F5 or clicking the Start button.
