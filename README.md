# .NET Lab Assignments

This repository contains multiple C# console application assignments for learning and practice.

## Assignments

- **Assignment_1**: Basic C# programs covering student details, arithmetic, conditionals, loops, grade calculation, prime and palindrome checks, and menu-based programs.
- **Assignment_2**: .NET Framework assignment focused on access modifiers, inheritance, namespaces, and cross-assembly behavior.
- **Assignment_3**: Beginner-level console menu with student details, sum, even/odd, largest number, and factorial programs.
- **Assignment_4**: Comprehensive delegate assignment covering custom delegates, unicast and multicast delegates, calculator operations, notification services, salary calculation via GetInvocationList(), and built-in Action, Func, and Predicate delegates. Theoretical questions, definitions, and syntax details are documented in `Theory_Questions.md`.
- **Assignment_5**: C# assignment project with menu-driven exercises covering arrays, classes, inheritance, method overloading, exception handling, and OOP concepts.
- **Assignment_6**: ADO.NET lab project covering SQL Server database operations, Connected and Disconnected CRUD architectures, and SqlCommandBuilder.

## Run Projects

Open the desired assignment folder and run the solution or project in Visual Studio or Visual Studio Code:

- `Assignment_1/Assignment1.sln`
- `Assignment_2/DotNetLabAssignment2.slnx`
- `Assignment_3/Assignment3.sln`
- `Assignment_4/Assignment4.sln`
- `Assignment_5/Assignment5.slnx`
- `Assignment_6/Assignment6.sln` (or `Assignment6.slnx`)

### Running via Terminal / Visual Studio Code

Navigate to any assignment folder and run:

```powershell
dotnet run
```

## Environment

- IDE: Visual Studio 2022 / Visual Studio Code
- Language: C#
- Platform: .NET 10 / .NET Framework 4.8
- Type: Console Applications
