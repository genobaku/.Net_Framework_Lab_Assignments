# .NET Lab Assignments

This repository contains multiple C# console application assignments for learning and practice.

## Assignments

- **Assignment1**: Basic C# programs covering student details, arithmetic, conditionals, loops, grade calculation, prime/palindrome checks, and menu-based programs.
- **Assignments2**: .NET Framework assignment focused on access modifiers, inheritance, namespaces, and cross-assembly behavior.
- **Assignment3**: Beginner-level console menu with student details, sum, even/odd, largest number, and factorial programs.
- **Assignment4**: About delegates and event handling.
- **Assignment5**: C# assignment project with menu-driven exercises covering arrays, classes, inheritance, method overloading, exception handling, and OOP concepts.
- **Assignment6**: ADO.NET lab project covering SQL Server database operations, Connected and Disconnected CRUD architectures, and SqlCommandBuilder.

## Run Projects

Open the desired assignment folder and run the solution or project in Visual Studio:

- `Assignment_1/Assignment1.sln`
- `Assignment_2/DotNetLabAssignment2.slnx`
- `Assignment_3/Assignment3.sln`
- `Assignment_4/Assignment4.sln`
- `Assignment_5/Assignment5.slnx`
- `Assignment_6/Assignment6.sln` (or `Assignment6.slnx`)

## Environment

- IDE: Visual Studio 2022
- Language: C#
- Platform: .NET 10 / .NET Framework 4.8
