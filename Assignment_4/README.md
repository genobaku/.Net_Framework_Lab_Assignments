# Assignment 4: Delegates in C#

This folder contains the complete solution for Assignment 4 on C# Delegates.

## Contents

- `Program.cs`: Executable C# programs demonstrating delegate mechanics, custom delegates, multicasting, calculator operations, notification broadcasting, salary component aggregation using GetInvocationList(), and the built-in Action, Func, and Predicate delegates.
- `Theory_Questions.md`: Complete theoretical questions and answers covering delegate definitions, purpose, general syntax, unicast vs. multicast comparisons, and standard generic delegates.
